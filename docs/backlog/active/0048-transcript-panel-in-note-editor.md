# Transcript panel in unified note editor

Adds the "Transcript" tab to the left panel of the note editor. Renders the note's transcript as read-only HTML via `pulldown-cmark` on the Rust backend. Replaces `NoteDetailPane`'s transcript rendering responsibility.

Depends on: 0044 (shell), 0045 (Written tab), 0046 (recording strip attaches the transcript). Build last in the 0045/0046/0047/0048 parallel group.

---

## Backend

### 1. Add `pulldown-cmark` to `src-tauri/Cargo.toml`

```toml
pulldown-cmark = "0.12"
```

### 2. Add `note_render_transcript_html` IPC command in `src-tauri/src/commands/history.rs`

```rust
#[tauri::command]
pub fn note_render_transcript_html(
    ctrl: State<'_, Arc<HistoryController>>,
    id: String,
) -> Result<String, AppError>
```

Delegate to `ctrl.render_transcript_html(&id).map_err(AppError::from)`.

### 3. Add `render_transcript_html` to `HistoryController` in `src-tauri/src/controllers/history.rs`

```rust
pub fn render_transcript_html(&self, id: &str) -> Result<String, String>
```

Steps:
1. Call `self.render_markdown(id)?` (existing method, already handles legacy sources) to get the markdown string.
2. Feed through `pulldown-cmark`:
   ```rust
   use pulldown_cmark::{html, Options, Parser};
   let parser = Parser::new_ext(&markdown, Options::all());
   let mut html_output = String::new();
   html::push_html(&mut html_output, parser);
   Ok(html_output)
   ```

No changes to `HistoryService` — this is pure transformation in the controller.

### 4. Register in `src-tauri/src/lib.rs`

Add `commands::history::note_render_transcript_html` to `tauri::generate_handler![]`.

### 5. Tests

In `src-tauri/src/controllers/history.rs` tests:

- `render_transcript_html_contains_paragraph_tag` — create a record with a single segment `"Hello world"`, call `render_transcript_html`, assert the result contains `<p>`.

## Frontend

### 1. Add tab strip to left panel in `note-editor.svelte`

The `activeTab` state (`'written' | 'transcript'`) was introduced in story 0046. Wire a tab strip at the top of the left panel:

```svelte
{#if hasTranscript}
<div class="shrink-0 flex border-b border-card px-4 gap-4">
  <button
    class="sf-label-sm py-2 border-b-2 {activeTab === 'written' ? 'border-fg text-fg' : 'border-transparent text-fg-dim'}"
    onclick={() => activeTab = 'written'}
  >Written</button>
  <button
    class="sf-label-sm py-2 border-b-2 {activeTab === 'transcript' ? 'border-fg text-fg' : 'border-transparent text-fg-dim'}"
    onclick={() => activeTab = 'transcript'}
  >Transcript</button>
</div>
{/if}
```

`hasTranscript` is derived: `$derived(record?.segments?.length > 0)`. When no transcript, Transcript tab is hidden and `activeTab` stays `'written'`.

### 2. Create `src/lib/ui/4_sections/TranscriptPanel.svelte`

Props:
```ts
let { noteId }: { noteId: string } = $props();
```

```svelte
<script lang="ts">
  import { onMount } from 'svelte';
  import { invoke } from '@tauri-apps/api/core';
  import ScrollBody from '@components/layout/ScrollBody.svelte';

  let { noteId }: { noteId: string } = $props();
  let html = $state('');

  onMount(async () => {
    html = await invoke<string>('note_render_transcript_html', { id: noteId });
  });
</script>

<div class="flex flex-col h-full min-h-0">
  <header class="shrink-0 flex items-center justify-between px-4 py-2 border-b border-card">
    <span class="sf-label-sm text-fg-dim">Transcript</span>
    <button
      class="sf-label-sm text-fg-dim hover:text-fg"
      onclick={() => navigator.clipboard.writeText(html.replace(/<[^>]+>/g, ''))}
    >Copy</button>
  </header>
  <ScrollBody>
    <div class="prose px-4 py-3 sf-body-sm text-fg" {@html html}></div>
  </ScrollBody>
</div>
```

> **Security note:** `html` is generated by Rust's `pulldown-cmark` from user-typed and Whisper-generated content — both originate from the local user, not from an external network source. The `{@html}` binding is appropriate here; this is not an XSS vector.

### 3. Render `TranscriptPanel` in `note-editor.svelte` left panel

```svelte
<div class="flex-1 min-h-0 min-w-0 overflow-y-auto">
  {#if activeTab === 'written'}
    <MarkdownEditor value={writtenContent} onchange={onContentChange} />
  {:else}
    <TranscriptPanel noteId={id} />
  {/if}
</div>
```

### 4. Default tab selection on load

In `note-editor.svelte` `onMount`, after loading the record:

```ts
if ((record.segments?.length ?? 0) === 0) {
  activeTab = 'written';
} else if (!record.written_content) {
  activeTab = 'transcript';
} else {
  activeTab = 'written';
}
```

### 5. Export from `src/lib/ui/4_sections/index.ts`

Add: `export { default as TranscriptPanel } from './TranscriptPanel.svelte';`

## SOLID / DRY expectations

- `render_transcript_html` in the controller calls the existing `render_markdown` — no duplication of segment→text logic.
- `pulldown-cmark` is the single markdown→HTML path; do not add a JS markdown renderer.
- `TranscriptPanel` is display-only; no editable affordances.
